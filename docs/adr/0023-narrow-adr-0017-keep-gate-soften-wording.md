# 0023 收窄 ADR-0017：保留硬闸门，只软化拒答措辞

Status: accepted
amends: ADR-0017（其「去硬闸门 / 全局软拒答」部分作废）

## 背景

ADR-0017 决定**全局软拒答**：删掉 `ragcore/services/rag_service.py::_has_evidence()` 的硬闸门，离题与否交给 LLM。用户复评（2026-09-15）推翻其代价判断：

- 代码改动**确实小**（删闸门 + prompt 措辞），但**删掉的是唯一的离题护栏**——prompt 是软的、不可靠；离题问题也一定走 LLM → **幻觉/越界概率上升**，对**法律问答**尤其敏感。
- 会让仓库现有 legal 证据**变假**（`results_scored.md` 的「拒答 21→12 / faithfulness 5.0」是硬闸门时代的数字），不重跑则锚点与实现不符。
- 跳出细节：`legal_web` 是**回归锚点/适配层**，"防幻觉"是它说服力的一部分——全局软化会**削弱锚点**。

## 决策

- **D1 保留 `_has_evidence()` 硬闸门与 `RELEVANCE_THRESHOLD`**：post-rerank 最优距离超阈 → **不调 LLM**、回模板。
- **D2 只软化「措辞」**：模板/提示更自然，不再生硬；**不改变「离题不生成」的行为**。
- **D3 作废 ADR-0017 的 D1/D2**（去闸门 / 全局软）；ADR-0017 的 **D3（检索层不动）保持不变**。
- **D4**：若将来记忆平面要软拒答，**另立 ADR**（对应 ADR-0017 的 option C：核心软 / 法律保留硬）。

## 理由

- 护栏与措辞是**两件事**：要"自然"只需改措辞（option B），无需承担幻觉风险。
- 保留闸门 → legal 锚点证据**不需要重跑**，仓库自洽。

Considered options:

- **B 保留闸门 + 软化措辞（采用）**——自然、零风险。
- **C 核心软 + 法律保留硬（备选，留待记忆平面）**——灵活性更高但多一层配置面。
- **A 全局软拒答（弃，原 ADR-0017 D1/D2）**——离题失去护栏 + 证据失效。
- **D 维持现状（弃）**——措辞仍生硬。

## Consequences

- `#27` 范围**收窄**为「措辞软化（+ 可选：把最优距离作为可观测置信度透出 SSE metadata）**移除**」。**不再需要** legal 评测重跑的前后对照（因为行为未变）。
- `RELEVANCE_THRESHOLD=0.85` 继续有效。
- 记忆平面若要软拒答 → 走 D4 新 ADR。

Relates: ADR-0017（被修订）、#27、`legal_web/tests/results_scored.md`。
