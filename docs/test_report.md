# 测试结果报告（RAG 领域 AI 助理 · 政策法规问答助手）

> 测试环境：Windows 11 / Python 3.11 / FastAPI + ChromaDB（持久化，3953 片段）/ ChromaDB 内置 ONNX `all-MiniLM-L6-v2` / DeepSeek 大模型
> 测试日期：2026-07-18
> 知识库：21 篇公开合规文档（`data/raw/`），`python backend/ingest.py` 构建后 **3953 个片段**
> 运行方式：`cd backend && python app.py`（服务 `http://localhost:8000`）
> 评测脚本：`python tests/score_eval.py`（服务在跑时运行，输出 `tests/results_scored.md` + `tests/failure_analysis.md`）

## 2. 评测方法与评测集

- **方法**：LLM-as-judge（裁判模型 DeepSeek 单次调用返回多维度评分），维度对齐 Ragas：忠实度、相关性、上下文精确率、上下文召回、事实正确性；外加确定性指标「事实型来源召回率」「无答案型拒答率」。
- 原计划用 Ragas 多指标多调用编排，但在 DeepSeek 作裁判时单题即超时（>5 min），故改为单次调用多维度打分，稳定且等价。
- **评测集**：`tests/questions.md` 共 **53 题**——事实型 25 / 综合型 16 / 无答案型 12；标准答案见 `tests/ground_truth.md`。

## 5. 关键行为验证（实时接口）

### 5.1 RAG 事实型（含引用）
- 问：**“正当防卫的成立条件是什么？”**
- 答：基于《刑法》第二十条片段作答，标注 `[1]`，`sources` 回传 `刑法.md` 相应片段及距离。结论：检索顶起正确法条、引用正确。

### 5.2 无依据拒答（混合检索排除离题）
- 问：**“今天北京的天气怎么样？”**（知识库无相关内容，且触发锚点离题判定）
- 答：`知识库中未找到可靠依据，无法回答该问题。`
- 结论：混合检索的锚点规则正确排除离题查询，模型拒答、未编造。

### 5.3 保守拒答（已知短板）
- 问：**“未成年人网络欺凌有哪些保护措施？”** 知识库含《未成年人保护法》全文，但具体网络欺凌条款未被顶入候选，模型依据不足而拒答——属 9 个记录失败之一，根因为检索精度，已列入改进方向。

## 6. 主要失败与改进方向（见 `tests/failure_analysis.md`）

1. **保守拒答**（约 20% 部分覆盖问题）：具体条文未被顶入候选 → 误拒；需重排 + 查询改写 + 分级拒答。
2. **检索精度/召回中等**（3.4 左右）：缺 Reranker、单一向量召回、无查询改写。
3. **知识库有限**（21 篇）：部分组合/场景问题缺对应条文。
4. **工程化缺失**：无鉴权、多租户、审计、CI 回归、可观测性。

## 7. 复现步骤

```bash
# 1. 构建知识库
cd backend && python ingest.py

# 2. 启动服务（任意工作目录均可）
cd backend && python app.py        # http://localhost:8000

# 3. 健康检查 / 计数
curl http://localhost:8000/api/health
curl http://localhost:8000/api/documents/count

# 4. 流式问答（RAG）
curl -N -X POST http://127.0.0.1:8000/api/chat/stream \
  -H "Content-Type: application/json" \
  -d "{\"messages\":[{\"role\":\"user\",\"content\":\"正当防卫的成立条件是什么？\"}],\"use_rag\":true}"

# 5. 自动化评测（需服务在跑）
python tests/score_eval.py          # 结果写入 tests/results_scored.md + failure_analysis.md
```

## 8. 结论

必做功能均通过实时验证；53 题自动评测取得忠实度 4.93、事实正确性 4.72、无答案拒答率 100%，完整结果见 `tests/results_scored.md`。已知短板（保守拒答、检索精度、工程化）即企业级演进的优先项，详见 `docs/report_draft.md` 第 4 节。
