# 测试问题集（政策法规问答助手）

格式：`- [类型] 问题文本`。由 `tests/run_eval.py` 解析并跑 RAG 与 LLM-only 两种模式。
类型需覆盖：事实型、综合型、无答案型（任务书 §2.6 要求）。
本集已扩充至 50 题，覆盖刑法、劳动合同法、民法典、公司法、行政处罚法、行政许可法、
道路交通安全法、消费者权益保护法、社会保险法、劳动法、个人信息保护法、未成年人保护法、
行政复议法、食品安全法、妇女权益保障法、反电信网络诈骗法、行政强制法、国家赔偿法、
个人所得税法/专项附加扣除、居住证等主要入库法典。
