## 3. 范围 A：来源约束核验（零 LLM）

### 3.1 规则（可复算，写死如下）

- **来源词表** = `data/corpus.json` 的 `source` 字段，49 个不同来源；`multihop:<i:04d>` ↔ 第 i 篇。
- **别名** = 来源名本体 + 三个前缀变体（`" | "` / `" - "` / `": "` 之前的部分），长度 < 3 丢弃；
  一个别名可映射多个来源（如 `BBC News` → 两个 feed）。本次别名表 59 条。
- **匹配** = 问题文本 `lower()` 后对别名做 **ASCII 词边界、大小写不敏感**的全词匹配
  （`(?<![a-z0-9])alias(?![a-z0-9])`）；同一来源一题只计一次。**不做语义消歧**。
- **证据集**：`A1` = `trace.final.evidence_ids`；`C15` = `control_rankings.json` 的 `ranked[:15]`
  （一次性 top-15 = A1 的实际展示额度上界，见 #74 `report.md` §2）。
- **致盲风险面（blind）** = 某被提及来源在 **gold** 里有文章、但在该臂证据集里**一篇都没有**。
- 分母：**D1** = 176 可答题；**D2** = 含 ≥1 显式来源提及的题；**D3** = (题 × 来源) 提及对；
  **D4** = 提及对中"该来源在 gold 里有文章"的对数。

### 3.2 数字

| 统计 | A1 | C15（一次性 top-15） |
|---|---|---|
| 含 ≥1 显式来源提及的题（D2 / D1） | **175 / 176（99.4%）** | 175 / 176 |
| 提及对（D3） | 367 | 367 |
| 提及对中该来源在 gold 里（D4） | **328（89.4%）** | 328 |
| 提及对中该来源**与 gold 无关**的题 | **0** | 0 |
| **致盲提及对**（来源在 gold、证据里一篇没有） | **82 / 328（25.0%）** | **36 / 328（11.0%）** |
| **致盲题数**（≥1 个致盲提及对） | **66 / 175（37.7%）** | **33 / 175（18.9%）** |
| 致盲题（**所有**在 gold 里的提及来源都未进证据） | 6 | 1 |
| 被提及来源的 gold 文章总数 | 449 | 449 |
| 其中**不在证据集**里的篇数 | **146（32.5%）** | **67（14.9%）** |
| 约束至少被满足一条的题 | 169 | 174 |

**规则敏感性**：只用**来源全名**（不加前缀别名）重算 → 核心计数**逐位相同**
（提及题 175 / 致盲对 82 / 致盲题 66；C15 为 175 / 36 / 33）。前缀别名只影响提及对分母
（367 vs 328），**不影响致盲结论**。

**这段数字说明了什么**：MultiHop-RAG 的题**几乎都在问题里点名来源**，而被点名的来源**几乎都在 gold 里**
（0 个反例）→ "来源约束"在本语料上**等价于一个 gold 指针**。因此
"点名来源却没拿到该来源文章"是一个**可核验的、句法层面的缺环证据**——
它不需要任何语义判断就能证明"这条约束没被满足"。

按 §3 的致盲状态切 66 道已判分题（A1 臂）：

| **致盲**（≥1 个点名来源的 gold 文章未进证据） | **26** | **26** | **100%** |
| 约束至少满足一条（非致盲） | 39 | 37 | 94.9% |

  —— 这正是 owner 说的"缺的东西不留痕迹"。本票给出的是这条机制**唯一可离线复算的面**。

## 6. 判定：A″ 的负结果该不该被读成"这个过滤器产出的报告更差"？

**不该。**（一句话版）

- A″ 量的是**筛选指标**（证据召回），本票补上**答案质量**后，两者**没有同向的坏消息**：
  证据召回显著低于同额度一次性检索（−0.21 vs C20），
  但在**运行时真正产出答案**的 66 道题上，**gold 不齐与 gold 齐的答案正确率没有差别**
  （2 道错题恰好一格一道；三档判分口径方向一致）。
- 因此把 A″ 的负结果读成"过滤器产出的**报告内容更差**"是**越界推论**：
  本票的数据只能说"**同等额度下没找到更多该找的文章**"，**不能**说"内容更差"。
- 但**也不能**读成"缺证据无害"：可核验的伤害面在**约束核验**上——
  **37.7%（66/175）的题**至少有一条**问题里显式点名**的来源约束没被满足，
  其中已产出答案的 26 道**全部判对**（§4）；另有 **62.5%（110/176）的题根本没有产出答案**（§5）。
- 供 owner 决策（**本票不实施、不定票**）：若要接着做 **#64 B（grounded verification）**，
  本票的数字把靶子从"**找齐 gold**"推向"**约束满足 / 可核验**"——
  后者有**零 LLM 可复算**的判据面（§3），且它捕捉的正是"答案对但依据没核"这类失效；
  "找齐 gold"在本测量里与答案正确率**没有可测关联**。

## 7. 边界与已知限制

- **外部语料只作机制证据**，不声称本 KB 增益（ADR-0026 D5/D6、ADR-0030 D7.5）。
- 一次观测（LLM 非逐字节确定）；答案与判分都基于 A″ **已落盘**的轨迹，未重跑。
- **别名匹配是机械规则**：不识别 `CBS Sports` ↔ `CBSSports.com` 这类改写（假阴性），
  也不做同形异义消歧（假阳性）——已用"只用全名"的敏感性核过，核心计数不变。
- 判分只在 **66** 道有答案的题上做（§2.2）；`fallback` / `budget` 组的答案正确率**不可得**。
- `det_match` 对 yes/no 类短 gold 宽松（先例口径）；已给出词级 / 严格下界（§2.3）。
- 致盲的定义是**来源级**（"该来源有没有文章进证据"），不是**文章级**的正确性判断；
  来源文章进了证据 ≠ 模型读到了它（A1 只给前 240 字 snippet，见 #74 §7.1）。
- 本票**不解释**额度 / 停止判据（属 #74 已冻结的事后分析），不动运行时。
