## B3 停止 / 早停 / 过检

- 触发分布：{'budget': 14, 'llm_enough': 133, 'no_new_ids': 29}
- 类别：{'budget': 14, 'complete': 70, 'premature': 63, 'stall': 29}
- **早停率**（仅 ① 触发且 Reach 缺）：63/176 = 0.3580；占 LLM 主动停 = 0.4737
- **过检率（强：r* 存在仍多跑）**：26 / 90，平均多跑 1.7308 轮
- **过检率（弱：某轮新增金标=0）**：65 / 176，平均浪费 1.8769 轮

**口径限制（必须随结论引用）**：
1. 用 gold 判「该不该停」默认所有金标都必要，而 evidence 列表可能含冗余 → **早停率是上界**（描述性、不校阈值，ADR-0017）；
2. 这是**我们自己的操作化**，与 Adaptive-RAG「路由误判 31%」**不是同一口径**，不得混引；
3. `Reach = G ∩ top-50(B1)` 只是**可达上界代理**——不在其中的金标是覆盖 / 索引问题，不算循环的错。
